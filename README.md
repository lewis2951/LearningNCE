# 新概念英语学习打卡应用

## 项目简介

新概念英语学习打卡应用是一款专为英语学习者设计的移动端应用，帮助用户跟踪学习进度，记录每日学习情况，并提供学习数据统计和分析功能。

## 功能特性

### 核心功能
- **用户认证**：注册、登录、个人信息管理
- **学习打卡**：每日学习记录、打卡确认
- **课程管理**：新概念英语1-4册课程展示、进度标记
- **进度追踪**：学习进度可视化、完成情况统计
- **数据统计**：学习时长、连续打卡天数、学习频率分析
- **学习提醒**：设置学习提醒时间

### 辅助功能
- **学习笔记**：允许用户添加、编辑、删除学习笔记
- **生词本**：记录和管理生词，跟踪掌握程度

## 技术架构

- **开发框架**：HarmonyOS SDK
- **开发语言**：ArkTS
- **UI框架**：HarmonyOS UI组件
- **数据存储**：本地存储（Preferences）

## 安装与运行

1. 确保您的开发环境已配置好HarmonyOS SDK
2. 克隆项目到本地
3. 使用DevEco Studio打开项目
4. 编译并运行到HarmonyOS设备或模拟器

## 使用说明

### 1. 注册与登录
- 首次使用时，点击「注册」按钮创建账号
- 已有账号直接登录

### 2. 每日打卡
- 进入「打卡」页面
- 点击「立即打卡」按钮完成当日打卡
- 查看打卡日历了解历史打卡情况

### 3. 课程学习
- 进入「课程」页面
- 选择要学习的册数（1-4册）
- 点击「标记完成」按钮记录学习进度
- 查看进度条了解学习完成情况

### 4. 学习统计
- 进入「统计」页面
- 查看总打卡天数、连续打卡天数、总学习时长和完成课程数
- 查看最近7天学习趋势图表

### 5. 个人中心
- 进入「我的」页面
- 修改个人信息
- 设置学习提醒时间
- 查看学习笔记和生词本

### 6. 学习笔记
- 进入「学习笔记」页面
- 点击「添加笔记」按钮创建新笔记
- 编辑或删除已有笔记

### 7. 生词本
- 进入「生词本」页面
- 点击「添加生词」按钮添加新单词
- 编辑或删除已有生词
- 使用滑块调整生词掌握程度

## 数据存储

应用使用HarmonyOS的Preferences进行本地数据存储，确保用户数据安全保存。数据包括：
- 用户信息
- 打卡记录
- 课程进度
- 学习笔记
- 生词本

## 注意事项

- 应用需要通知权限以发送学习提醒
- 建议定期备份数据以防止数据丢失
- 目前仅支持本地存储，数据仅保存在当前设备
